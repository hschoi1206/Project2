# CLAUDE.md

PJT 손익변동 영향요인 대시보드 프로젝트. 작업 전 반드시 `GUIDELINE.md`를 읽는다.
충돌 시 본 문서가 우선한다. 지침에 없는 결정은 임의로 하지 말고 사용자에게 질문한다.

## 무엇을 만드는가
- `data/<기준일>.xlsx` 스냅샷들을 읽어 검증한 뒤, 단일 오프라인 HTML 대시보드를 생성한다.
- 경영진용. 화면 그대로 A4 가로로 잘림 없이 인쇄(PDF)되어야 한다.

## 절대 규칙
1. `00_원자료/`는 읽기 전용. 수정·이동·삭제 금지.
2. 원자료에 없는 숫자를 만들지 않는다. 모르면 빈칸 + 질문.
3. 검증·대사 실패 시 HTML을 생성하지 않는다. 데이터나 계산식을 고쳐서 통과시키지 않는다. 원인을 보고한다.
4. 확률·기대값 계산 금지. Downside와 Upside 합산·상계 금지.
5. 회계 계산(진행률, 매출, 당해영향 산정) 금지. 입력값만 사용한다.
6. 종결 요인(ITC 편입·소멸)은 합계에서 제외한다.
7. 외부 CDN·URL·폰트 금지. 패키지는 Python 3 + openpyxl만 쓴다. 차트는 인라인 SVG로 그린다.
8. 외부 원격 저장소 push 금지. 로컬 git만 사용한다.
9. `data/*.xlsx`는 사용자 입력 파일이다. 사용자가 지시했을 때만 작성하고, 작성 후 검토를 받는다.
10. 한 번에 한 영역만 수정 → 로컬 커밋 → `CHANGELOG.md` 기록.

## 핵심 용어 (상세: GUIDELINE §3)
- ITC = 완성예측원가 (QG 승인, 연 1회 개정)
- 영향요인 = ITC 미반영, 트리거 발생 시 손익 임팩트. 상태: 트리거 대기 / 트리거 발생 / ITC 편입 / 소멸
- 준공영향(주) / 당해영향(보조). 부호는 Down 음수, Up 양수. 저장 단위 원, 표시 단위 억원(소수 1자리)

## 명령
- 빌드: `python scripts/build.py` → `output/dashboard_<기준일>.html`, `output/reconciliation_<기준일>.md`

## 화면 순서
KPI(준공·당해 2줄) → MTA 차트 → 손익 브릿지 → 변동 내역 → 영향요인 표. 내부 스크롤 영역은 원칙적으로 금지한다.
