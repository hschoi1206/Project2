# 현장 보고 대시보드 (v0.1)

월간 현장 보고 엑셀 템플릿을 읽어 임원 보고용 대시보드 데이터(JSON)로 변환한다.

```
[입력] data/raw/*.xlsx  →  [처리] src/parse_report.py  →  [출력] data/processed/dashboard_data.json  →  (v0.3) 대시보드 HTML
```

> ⚠️ 이 레포에는 **더미 데이터만** 올린다. 실제 현장 파일은 `.gitignore`로 커밋이 차단된다(`sample_*.xlsx`만 허용).

## 템플릿 구조 (시트 4개)

| 시트 | 형태 | 열 |
|---|---|---|
| 현장정보 | 항목/값 (세로) | 보고월, 현장명, 발주처, 위치, 공사기간_시작/종료, 계약금액_억원, **실행예산_억원**, 현장소장, 주요공종 |
| 공정률 | 월별 1행, 누계 | 보고월, 계획공정률(%), 실적공정률(%) |
| 예산집행 | 월별 1행, 누계 | 보고월, 계획집행누계(억원), 실적집행누계(억원) |
| 리스크 | 리스크 1건 1행 | ID, 리스크항목, 분류, 영향도(상/중/하), 발생가능성(상/중/하), 담당자, 등록일, 조치계획, 진행상태(미착수/진행중/완료), 목표완료일, 비고 |

매월 작업: `현장정보`의 보고월 변경 → `공정률`·`예산집행`에 1행 추가 → `리스크` 상태 갱신.

## 계산 규칙

- **예산집행률** = 실적집행누계 ÷ 실행예산 × 100
- **리스크 등급** = 영향도 × 발생가능성 (상3·중2·하1) → 6↑ High, 3~4 Medium, 1~2 Low
- **기한초과** = 진행상태 ≠ 완료 이고 목표완료일 < 보고월 말일

## 검증 (양식 오류 시 실행 중단)

필수 시트·열 누락, 보고월 행 누락, 중복 보고월, 공정률 0~100 범위 이탈, 숫자 아닌 값, 상/중/하·진행상태 허용값 이탈, 리스크 ID 중복.

## 실행

```bash
pip install -r requirements.txt
python scripts/make_sample_template.py                     # 더미 템플릿 생성
python src/parse_report.py data/raw/sample_report_2026-09.xlsx
python -m pytest -q                                        # 테스트
```
