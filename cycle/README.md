# 주기 기록 (Cycle Tracker PWA)

생리 시작일 기록 → 주기 추이 그래프 → 다음 주기 예측을 하는 오프라인 웹앱.

## 기능
- 기록 입력: 시작일(필수), 종료일·메모(선택), 수정·삭제, 과거 기록 일괄 붙여넣기
- 그래프: 주기 길이 추이 / 타임라인 — 두 손가락 확대·축소, 한 손가락 좌우 이동, 두 번 탭 초기화, 탭 시 상세
- 예측: 최근 6회 유효 주기(15~60일) 평균으로 향후 3회 예정일, ±1σ 범위, 배란(예정일−14일)·가임기(−5~+1일) 추정
- 백업: JSON 내보내기/불러오기(합치기 또는 교체)

## 데이터
기기 브라우저 localStorage(`cycleTracker.v1`)에만 저장되며 서버로 전송되지 않습니다.

## 설치 (Android)
1. GitHub Pages로 배포된 `…/cycle/` 주소를 Chrome으로 열기
2. 메뉴 ⋮ → **앱 설치**(또는 홈 화면에 추가)

※ 예측은 통계적 추정이며 피임·진단 목적으로 사용할 수 없습니다.
